# Limitations

- The populated portfolio is fictional and its figures are model data, not production telemetry.
- The operator console persists only in the current browser’s local storage; there is no multi-user sync or server-side history.
- Framework mappings are an engineering crosswalk and evidence aid, not legal advice or a declaration of compliance.
- The static site has no authentication or role-based access control.
- The repository does not implement an ingestion pipeline for uploaded evidence; its model is edited through the console and JSON fixtures.
- The system does not claim that a coverage percentage captures every governance risk.
